# Шрифт для PDF

`DejaVuSans.ttf` лежит в репозитории, а не ставится пакетом, потому что сборка
идёт через Nixpacks: системных шрифтов в образе может не оказаться вовсе, и
тогда PDF выходит пустыми квадратами вместо кириллицы. Файл весит 744 КБ —
дешевле, чем зависимость от содержимого чужого базового образа.

Лицензия — свободная (Bitstream Vera / DejaVu), использование и
распространение разрешены: https://dejavu-fonts.github.io/License.html
