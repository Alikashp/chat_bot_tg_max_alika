# Примеры к приколам

Картинки, которые бот показывает альбомом перед списком приколов: подпись
«🧸 Фигурка в коробке» ничего не говорит тому, кто такой фигурки не видел.

Имя файла — идентификатор прикола из `config/presets.py`. Расширение любое из
`.jpg`, `.jpeg`, `.png`. Формат проверяется по сигнатуре, а не по расширению:
файл не той природы в меню не попадёт, а в лог придёт `preset_example_not_an_image`.

| Файл | Прикол |
|---|---|
| `lego.*` | 🧱 Лего |
| `bad_day.*` | 🏚 Плохой день |
| `id_photo.*` | 🪪 Фото на документы |
| `figurine.*` | 🧸 Фигурка в коробке |
| `polaroid_child.*` | 📷 Я и я в детстве |

Картинки читаются один раз на старте. Добавили или заменили — нужна выкатка.

Прикол без картинки работает по-прежнему и остаётся в меню: иначе новый прикол
пришлось бы ждать вместе с картинкой к нему, а реестр перестал бы быть точкой
расширения (критерий приёмки A1).

**Про вес.** Альбом уходит на каждое открытие меню только в первый раз: дальше
адаптер отправляет уже загруженные картинки ссылкой. Память живёт до выкатки.
Разумный размер файла — до 300 КБ на картинку.
