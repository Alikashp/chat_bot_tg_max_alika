# Юридические документы

Здесь лежат исходники оферты и политики в том виде, в каком они публикуются.
Репозиторий — источник правды: опубликованная страница должна совпадать с
файлом отсюда, а правки идут сначала сюда.

## Что осталось заполнить

| Плейсхолдер | Чем заменить | Где |
|---|---|---|
| `[ДАТА]` | дата публикации, например «31 августа 2026» | оба документа |
| `[@имя_бота]` | имя бота: `@имя` в Telegram и в MAX | оба документа |
| `[ССЫЛКА]` | адрес второго документа на telegra.ph | оба документа, взаимные ссылки |
| `[@аккаунт_поддержки]` | аккаунт, куда писать по вопросам | соглашение, §9.5 |

Электронная почта уже подставлена: `fibonaccislides@mail.ru`.

## Порядок публикации

Ссылки в документах взаимные, поэтому публикуется в два прохода.

1. Опубликовать оба документа на telegra.ph как есть — адреса появятся сразу.
2. Подставить в текст полученные адреса, дату, имя бота и аккаунт поддержки.
3. Отредактировать обе страницы (telegra.ph хранит право правки в том же
   браузере, где страница создана, — не чистить куки и не менять браузер).
4. Обновить файлы в этом каталоге теми же текстами.
5. Прописать в Railway `OFFER_URL`, `PRIVACY_URL` и `DOCS_VERSION`.

До шага 5 бот оплату не показывает: вместо неё экран «оплата скоро». Это
осознанно — брать деньги, не показав условия, нельзя.

## Про версию документов

`DOCS_VERSION` — строка вида `2026-08-31`, совпадающая с датой редакции в
самих документах. Она записывается в каждый заказ и в лог согласия, поэтому
менять её нужно при каждой правке текстов: иначе по записи «согласился с
редакцией такой-то» нельзя будет понять, с чем именно.
